## ค่าคงที่ที่พิสูจน์แล้ว (จากฟังก์ชันของบีน — ใช้ต่อ ไม่ต้องคิดใหม่)
- Spine: L = 400 px, ω = π rad/s, Δφ = 0.5712 rad/ข้อ, A_MAX = 48 px, N = 12 จุด, arc-length correction (ลำตัวยืด 0.0%)
- Gerstner 4 ระลอก: A = 14/8/4.5/2.5 px, λ = 320/190/115/70 px, Q = 0.90/0.80/0.70/0.60, ω = √(g·k) dispersion ตรง g = 490.5 px/s², crest/trough 0.88
- อนุภาค: Spout 250 จุด กรวยครึ่งมุม 15° v0 ~ N(540,60) px/s / Splash 400 จุด มุม 30–75° / Snow 80 จุด random walk (std โตตาม √t)

- Polish: grain strength ~6 ถ่วงตามความสว่าง, CA 1.95 px, motion blur รัศมีโตตาม speed

## สิ่งที่ต้องเขียนโค้ดใหม่ (ยังไม่มีในฟังก์ชัน 5 ชิ้น)
1. **Breach ballistics** — วิถีพาราโบลา 3 ช่วง (Pre-Breach 160–180 / Phase Boundary 181–210 / Ballistic Apex 211–320 / Re-entry 321–360) + แรงหน่วงผิวน้ำ + Axial Roll + Cavity/White Water (ตาม Handoff §1.3)
2. **Telemetry โหมด breach** — speed/pitch จากพาราโบลาแทน travelling wave (ค่าเดิมใช้ได้แค่ตอนว่ายน้ำ)
3. **หอยเชลล์เปิด 50° + ไข่มุกทอง** — โมเดลหอย (มุมเปิด 0° → 50° เฟรม 90–160) + แสงทองของไข่มุก
4. **เสียง NumPy synth ทั้งแทร็ก** — ping ×3, whoosh, splash, hiss, room tone; loudnorm −16 LUFS (วิธี A ที่ใช้กับคลิปพายุสุริยะ: ตัดช่องว่างเหลือ 90 ms + room tone pink noise lowpass 300 Hz RMS −50 dBFS)

## QC ก่อนส่งฟิลิป (บีนตรวจเอง + AGY/Codex ตรวจขนาน)
- **Contact-sheet QC** — รวมเฟรมทั่ว 12 วิเป็นภาพรวมแผ่นเดียว (เช่น 6×6 = 36 เฟรม ทุก 0.33 วิ) ดูความต่อเนื่องวาฬ/คลื่น/อนุภาคทีเดียว (บทเรียน Warodom)
- **เฟรมจุดเปลี่ยน** — ตรวจเฟรมจริงที่ f45/68/90 (โซนาร์), f160–180 (หอยเปิด+เตรียมพุ่ง), f181/211/321 (เปลี่ยนโหมด), f348–360 (settle ก่อนจบ)
- **Telemetry cross-check** — drag/speed² คงที่ spread 0.000% ทั้งโหมดว่ายน้ำและโหมด breach
- **QC เสียงแบบ Earshot** — เทียบเสียง synth กับเสียงจริงอ้างอิงด้วย spectrogram จับเสียงปลอมแบบ "วาบวืด" ก่อนส่ง (ห้ามเลเยอร์เสียงจริงทับ synth โดยไม่ขอฟิลิปก่อน — ขัดล็อก synth)
- **สเปกไฟล์** — 720×1280, 30 fps, 12.00 วิ, 360 เฟรม, มีเสียง, −16 LUFS
